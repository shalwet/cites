1.1. Hello, World!

Напишите программу, которая выводит на экран фразу "Привет, мир!". В Python для этого используется функция print().

print("Привет, мир!")

Задание

Измените код так, чтобы программа выводила ваше имя.

💡 Подсказка
Замените строку внутри кавычек. Например: print("Александра")

1.2. Переменные и типы

Переменные — это именованные ячейки памяти. В Python не нужно явно указывать тип данных, он определяется автоматически.

name = "Алексей" age = 25 height = 1.85 is_student = True print(f"Имя: {name}, Возраст: {age}")

Задание

Создайте переменную city со значением "Москва" и выведите фразу "Я живу в Москве".

💡 Подсказка
Используйте f-строки: print(f"Я живу в {city}")
Далее: 1.3. Ввод и вывод →

1.3. Ввод и вывод

Для получения данных от пользователя используется функция input(). Она всегда возвращает строку.

name = input("Введите ваше имя: ") age = int(input("Введите ваш возраст: ")) print(f"Привет, {name}! Тебе {age} лет.")

Задание

Спросите у пользователя его любимый цвет и выведите ответ в формате "Ваш любимый цвет — [цвет]".

💡 Подсказка
Используйте input() для вопроса и print() для вывода ответа.

2.1. Условный оператор if

Оператор if позволяет выполнять код только при выполнении определенного условия.

age = int(input("Сколько вам лет? ")) if age >= 18: print("Доступ разрешен") else: print("Доступ запрещен")

Задание

Напишите программу, которая проверяет, является ли введенное число четным. Подсказка: используйте оператор % (остаток от деления).

💡 Подсказка
Число четное, если num % 2 == 0.
Далее: 2.2. Циклы for и while →

2.2. Циклы for и while

Циклы позволяют повторять один и тот же блок кода многократно.

# Цикл for (повторить 5 раз) for i in range(5): print(f"Итерация {i + 1}") print("---") # Цикл while (пока условие истинно) counter = 0 while counter < 3: print(f"Счетчик: {counter}") counter += 1

Задание

Используя цикл for, выведите на экран числа от 1 до 10.

💡 Подсказка
Функция range(1, 11) вернет числа от 1 до 10 включительно.

3.1. Списки (Lists)

Список — это упорядоченная изменяемая коллекция элементов.

fruits = ["яблоко", "банан", "вишня"] print(fruits[0]) # Доступ по индексу fruits.append("груша") # Добавление элемента print(fruits)

Задание

Создайте список из трех городов. Добавьте в конец списка еще один город и выведите итоговый список.

💡 Подсказка
Метод .append() добавляет элемент в конец списка.
Далее: 3.2. Словари (Dictionaries) →

3.2. Словари (Dictionaries)

Словарь — это неупорядоченная (до Python 3.7) коллекция пар "ключ: значение".

user = { "name": "Иван", "age": 30, "city": "Казань" } print(user["name"]) user["age"] = 31 print(user)

Задание

Создайте словарь с информацией о книге (название, автор, год). Измените год издания на более поздний.

💡 Подсказка
Для изменения значения обратитесь к нему по ключу: book["год"] = 2025.
Далее: 4.1. Создание функций →

4.1. Создание функций

Функции позволяют изолировать логику и переиспользовать код. Создаются с помощью ключевого слова def.

def greet(name): return f"Привет, {name}!" print(greet("Александра")) print(greet("Мир"))

Задание

Напишите функцию square(), которая принимает число и возвращает его квадрат.

💡 Подсказка
Квадрат числа — это число, умноженное само на себя: return n * n.
Далее: 4.2. Аргументы и return →

4.2. Аргументы и return

Функции могут принимать значения (аргументы) и возвращать результат своей работы.

def add(a, b): return a + b x = 10 y = 20 result = add(x, y) print(f"Сумма {x} и {y} равна {result}")

Задание

Напишите функцию get_full_name(), которая принимает имя и фамилию, а возвращает полное имя (через пробел).

💡 Подсказка
Используйте f-строку внутри функции: return f"{first} {last}".
